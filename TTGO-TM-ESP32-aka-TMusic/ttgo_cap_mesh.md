# TTGO-TM ESP32 ("TMusic") — Base Tray (Mesh / Import Wrapper)

## Overview

Exact reproduction of the base tray. [`ttgo_cap_mesh.scad`](ttgo_cap_mesh.scad)
imports the original CATIA-exported mesh **`ttgo-cap-2.stl`** verbatim via
OpenSCAD's `import()`, so the geometry is 100 % faithful to the source part.

> **Naming note:** the source file is called *cap*, but the part is the deep
> **base tray**, not a lid.

Use this file when you need the real geometry. For an editable parametric
approximation, see [`ttgo_cap.scad`](ttgo_cap.md).

> The source mesh must sit beside the `.scad` file (it does, in this folder).

## Modules

| Module | Purpose |
|--------|---------|
| `ttgo_cap_mesh()` | Import the tray mesh as-is |
| `debug_axes(length)` | XYZ axes at origin |
| `debug_bounds()` | Transparent bounding box |
| `debug_recenter()` | Same mesh shifted so bbox-min sits at the origin |
| `assembly_mesh()` | Tray + bezel meshes shown together in native coords |

## Notes

- `convexity = 10` is set so the preview renders correctly through the deep
  cavity.
- The cap (z −20.29 … 1.86) and the body (z −3.54 … 11.46) share the same X/Y
  datum and overlap near z ≈ 0, so `assembly_mesh()` shows the closed
  enclosure.
