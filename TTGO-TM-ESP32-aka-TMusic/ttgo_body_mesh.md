# TTGO-TM ESP32 ("TMusic") — Front Bezel (Mesh / Import Wrapper)

## Overview

Exact reproduction of the front bezel. [`ttgo_body_mesh.scad`](ttgo_body_mesh.scad)
imports the original CATIA-exported mesh **`ttgo-body-2.stl`** verbatim via
OpenSCAD's `import()`, so the geometry is 100 % faithful to the source part.

Use this file when you need the real geometry (final print, accurate fit
checks). For an editable parametric approximation, see
[`ttgo_body.scad`](ttgo_body.md).

> The source mesh must sit beside the `.scad` file (it does, in this folder).

## Source Mesh

| Property | Value |
|----------|-------|
| File | `ttgo-body-2.stl` |
| Generator | "STL generated by Digitized Shape Editor / CATIA" |
| Triangles | 54,112 |
| Min [X,Y,Z] mm | [-36.675, -44.423, -3.540] |
| Max [X,Y,Z] mm | [ 39.525, 5.100, 11.460] |
| Size [W,D,H] mm | [ 76.200, 49.523, 15.000] |

The mesh origin is interior to the part (CATIA digitised-shape origin), not at
a corner.

## Modules

| Module | Purpose |
|--------|---------|
| `ttgo_body_mesh()` | Import the bezel mesh as-is |
| `debug_axes(length)` | XYZ axes at origin |
| `debug_bounds()` | Transparent bounding box |
| `debug_recenter()` | Same mesh shifted so bbox-min sits at the origin |

## Notes

- `convexity = 10` is set so the preview renders correctly through the
  bezel's openings.
- Native coordinates are shared with `ttgo_cap_mesh.scad`; importing both in
  native coords shows them already mated.
